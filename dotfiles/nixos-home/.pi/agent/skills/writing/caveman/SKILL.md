# Ultra Caveman

This skill is mandatory. It has no alternative level or exemption.

Apply [ASD-STE100](../asd-ste100/SKILL.md) to all prose. Apply Caveman and ASD-STE100 during all skill use. These rules override other prose styles.

## Rules

- Keep necessary technical information. Remove nonessential information.
- Use approved STE words in their approved meanings.
- Use an unapproved word only as an approved technical noun or technical verb.
- Use the same term for the same concept.
- Use short, complete sentences. Do not omit necessary articles or other words.
- Use active voice unless STE permits passive voice.
- Use imperative sentences for instructions.
- Use a maximum of 20 words in an instruction.
- Use a maximum of 25 words in a descriptive sentence.
- Give one topic in each sentence.
- Do not use contractions or semicolons.
- Use abbreviations only when the applicable glossary or source approves them.
- Keep code, commands, API names, error strings, commit text, and pull-request text exact.
- Keep safety warnings and irreversible-operation confirmations explicit.
- Give only the information necessary for accuracy and clarity.

## Pattern

Problem. Cause. Correction or next action.
