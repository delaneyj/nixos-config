# Grilling

Use only for required user decisions.

1. Ask one question at a time. Wait for the answer.
2. Resolve prerequisite decisions before dependent ones.
3. Ask one clarifying question and include a recommended answer.
4. Verify facts from files, tools, and sources. Ask user only for choices.
5. Stop before implementation until user confirms shared understanding.

Complete when no unresolved decision can change the chosen direction.
