# Grilling

Interview the user until you and the user have the same understanding.

1. Map the decision tree.
2. Resolve prerequisite decisions before dependent decisions.
3. Ask one question. Wait for the answer.
4. Give a recommended answer with each question.
5. Find facts in files, tools, and primary sources. Ask the user only for decisions.
6. Stop before implementation until the user confirms the understanding.

Complete the interview only when no unresolved decision can change the selected direction.
