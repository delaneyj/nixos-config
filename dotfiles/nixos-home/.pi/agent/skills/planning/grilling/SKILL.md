# Grilling

Interview the user until both sides have the same understanding.

1. Map the decision tree.
2. Resolve prerequisite decisions before dependent decisions.
3. Ask one question at a time and wait for the answer.
4. Give a recommended answer with each question.
5. Find facts from files, tools, and primary sources. Ask the user only for decisions.
6. Stop before implementation until the user confirms the understanding.

Completion requires no unresolved decision that can change the selected direction.
